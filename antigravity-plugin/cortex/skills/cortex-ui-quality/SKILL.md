# Cortex UI Quality

## Skill order

Use only what the task needs:

1. `cortex-ui-ux-pro-max` for design system, platform and UX decisions.
2. `cortex-taste` for visual hierarchy, typography, spacing and anti-generic art direction.
3. `cortex-awesome-design` when a DESIGN.md-style visual direction/reference is useful.
4. Inspo MCP when enabled and real production references would materially help.
5. `cortex-image-to-code` only when a supplied/generated visual reference must be translated faithfully.
6. `cortex-web-design-guidelines` after implementation for UI/accessibility review.
7. `/cortex-playwright` for actual browser inspection.

Do not copy another site's identity or proprietary assets. Use references to understand layout, rhythm, interaction and visual systems.

## Required UI evidence

Check desktop and narrow/mobile layouts, overflow, typography, contrast, focus/keyboard states, loading/empty/error states, hover/active/disabled states, image failures, console errors and core interactions. A compile-only pass is not UI verification.
