# Cortex Research

Research only when local repository evidence is insufficient or freshness matters.

- Prefer official documentation and primary sources for technical facts.
- Use `cortex-agent-reach` when installed and useful; otherwise use native web research.
- Keep searches scoped to the current decision.
- Return the conclusion, version/date, constraints and source evidence—not a transcript dump.
- Do not persist large raw research results into project memory; store only decisions that affect implementation.
