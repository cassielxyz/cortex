# Selective Skill Routing

Cortex keeps its own first-party orchestration skills in the workspace plugin and downloads only the external skills a task needs.

Examples:

- architecture/new feature → Superpowers brainstorming + writing plans;
- debugging → systematic debugging;
- implementation → test-driven development;
- UI → UI/UX Pro Max + Taste + web design guidelines, optionally Awesome Design/Inspo/image-to-code;
- completion → verification-before-completion;
- token pressure → Caveman output discipline;
- research → Agent Reach when installed/useful, otherwise native web research.

The user can always invoke the namespaced skills directly, such as `/cortex-taste`, after installation.
